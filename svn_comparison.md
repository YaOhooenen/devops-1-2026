# SVN vs Git

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
В Git ветка — указатель на коммит. В SVN — копирование директории на сервере.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет. SVN централизованная: коммит уходит на сервер.

## 3. В каких сценариях SVN предпочтительнее Git?
Legacy-проекты, госсектор и банки, большие бинарные файлы.
